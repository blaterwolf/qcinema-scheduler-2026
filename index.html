Back up your plan

Your schedule and posters are stored in this browser only. To put them on your phone or another browser, export a backup here, then import that file there. Clearing this site's data deletes them, and Safari can clear it if you don't open the site for a week, so export a fresh copy after big changes.

This isn't the QCinema Interactive backup. The “My Schedule” backup you save on qcinema.ph/interactive can't be imported here, and this planner's backup can't be imported there. Each one only reads its own files.
